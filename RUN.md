# Как запустить проект

## Что нужно

| Задача | Что установить |
|--------|----------------|
| Посмотреть демо | только браузер (Chrome, Firefox, Safari, Edge) |
| Запустить через локальный сервер | Node.js или Python — на выбор |
| Запустить тесты | Node.js **22 или новее** |

Проверить версию Node.js:

```bash
node -v
```

## 1. Скачать проект

```bash
git clone https://github.com/GiorgiBarbariani/graph.git
cd graph
```

Или на странице репозитория нажмите **Code → Download ZIP** и распакуйте архив.

## 2. Открыть демо

### Вариант А — просто открыть файл

Дважды кликните по `index.html` в папке проекта. Сборка и установка зависимостей не нужны: график — это один файл `combo-chart.js`.

Из терминала:

```bash
# Windows
start index.html

# macOS
open index.html

# Linux
xdg-open index.html
```

### Вариант Б — через локальный сервер

Нужен, если страница открывается внутри другого проекта или браузер ограничивает работу с `file://`.

```bash
npm start
```

Откройте http://localhost:8080. При первом запуске `npx` скачает пакет `serve`, поэтому нужен интернет.

Без Node.js, если установлен Python:

```bash
python -m http.server 8080
```

Остановить сервер — `Ctrl + C`.

## 3. Что есть на странице

1. **«Как на записи»** — график с данными из видео на розовом фоне.
2. **«30 дней случайных данных»** — график на всю ширину; кнопка **«Сгенерировать новые данные»** перерисовывает его.
3. **Код первого графика** — готовый пример инициализации.

Как взаимодействовать с графиком:

- **Мышь** — наведите курсор, появится тултип со значениями всех четырёх рядов.
- **Телефон** — коснитесь графика; тап мимо графика скрывает тултип.
- **Клавиатура** — `Tab` до графика, затем `←` `→` по датам, `Home` / `End` — первая и последняя дата, `Esc` — скрыть.

## 4. Запустить тесты

```bash
npm install
npm test
```

`npm install` ставит только `jsdom` — он нужен тестам, в сам график не попадает. В конце вывода должно быть:

```
ℹ tests 81
ℹ pass 81
ℹ fail 0
```

## 5. Подключить график в свой проект

Скопируйте `combo-chart.js` к себе и передайте четыре ряда данных:

```html
<div id="chart" style="width: 350px"></div>
<script src="combo-chart.js"></script>
<script>
  new ComboChart('#chart', {
    area:   { name: 'Cost',          data: [['2026-06-10', 2.04],   ['2026-06-11', 25.85]] },
    bar:    { name: 'CPA',           data: [['2026-06-10', 0.68],   ['2026-06-11', 0.86]] },
    spline: { name: 'ROI confirmed', data: [['2026-06-10', 610.78], ['2026-06-11', 180.5]] },
    line:   { name: 'Conversions',   data: [['2026-06-10', 3],      ['2026-06-11', 30]] }
  });
</script>
```

Все опции, методы и примеры для React / TypeScript — в [README.md](README.md).

## Если что-то не работает

| Проблема | Решение |
|----------|---------|
| Пустая область вместо графика | Откройте консоль браузера (`F12` → Console) и посмотрите ошибку. Частые причины: неверный путь к `combo-chart.js` или селектор контейнера не найден (`container not found`). |
| График нулевой высоты | Задайте контейнеру высоту через CSS или передайте опцию `height`. |
| `npm start` не запускается | Нужен интернет для первой загрузки `serve`, либо используйте `python -m http.server 8080`. |
| Порт 8080 занят | `npx serve -l 3000 .` или `python -m http.server 3000`, затем откройте http://localhost:3000. |
| `npm test` падает с ошибкой про версию Node или `jsdom` | Обновите Node.js до 22+ (https://nodejs.org), затем снова `npm install`. |
| Ошибка `cannot parse time value` | Даты передаются как `'YYYY-MM-DD'`, timestamp в миллисекундах или объект `Date`. |
